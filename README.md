# MyVPN22 — сборки для Android

Официальные APK приложения MyVPN22. Здесь публикуются **только готовые сборки** — исходного кода приложения в этом репозитории нет.

## Что лежит в релизах

- `myvpn22-<версия>.apk` — установочный файл;
- `myvpn22-<версия>.apk.sha256` — контрольная сумма SHA-256;
- `version.json` — описание последней версии для автообновления;
- `THIRD_PARTY_NOTICES.md` — лицензии стороннего открытого ПО.

## Проверка APK

Windows (PowerShell):

```powershell
Get-FileHash .\myvpn22-<версия>.apk -Algorithm SHA256
```

Linux / macOS:

```sh
sha256sum myvpn22-<версия>.apk
```

Сумма должна совпадать с содержимым файла `.sha256` из того же релиза.

## Требования

Android 8.0 (API 26) и новее. Приложение работает только с подпиской MyVPN22.
