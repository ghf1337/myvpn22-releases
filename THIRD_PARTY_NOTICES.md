# Сторонние компоненты (заготовка)

Приложение MyVPN22 для Android использует следующее открытое ПО.
Точные версии и ссылки на исходники будут указаны к первому релизу.

| Компонент | Лицензия | Исходники | Версия |
|---|---|---|---|
| Xray-core | MPL-2.0 | https://github.com/XTLS/Xray-core | будет указана |
| AndroidLibXrayLite (`libv2ray.aar`) | проверяется | https://github.com/2dust/AndroidLibXrayLite | будет указана |
| mihomo (отдельный процесс, без изменений) | GPL-3.0 | https://github.com/MetaCubeX/mihomo | тег будет указан |
| hev-socks5-tunnel | MIT | https://github.com/heiher/hev-socks5-tunnel | будет указана |
| AndroidX / Jetpack Compose | Apache-2.0 | https://android.googlesource.com/platform/frameworks/support | будет указана |
| Kotlin, kotlinx.coroutines, kotlinx.serialization | Apache-2.0 | https://github.com/JetBrains/kotlin | будет указана |
| OkHttp | Apache-2.0 | https://github.com/square/okhttp | будет указана |

Полные тексты лицензий будут приложены к первому релизу.
